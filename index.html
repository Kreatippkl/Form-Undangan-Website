Perhatian

Dimohon untuk memperhatikan penulisan huruf kapital, tanda baca, dan gelar saat mengisi data calon pengantin. Data yang dikirim akan langsung kami proses via copy-paste.

PETUNJUK PENGIRIMAN
  1. Kirim Foto maks. 12 foto ke WhatsApp kami dalam bentuk dokumen file agar kualitas foto tidak pecah.
  2. Jika formulir/kolom tertentu tidak ingin diisi, cukup ketik tanda strip ( - ).
  3. Klik tombol "Kirim ke WhatsApp" di halaman akhir untuk menghubungkan ke customer service.
  4. Pastikan seluruh teks pesan terkirim lengkap di jendela chat.
